# 学生管理系统（Student CMS）

一个基于 **Python 面向对象** 的控制台学生信息管理系统，支持角色权限、学生信息的增删改查、输入校验、同名去重、JSON 文件持久化，以及 Excel 批量导入导出。

## 功能特性

- 角色权限：管理员可增删改查；普通老师只能查看和导出，不能修改数据
- 添加 / 删除 / 修改 / 查询学生信息（姓名、性别、年龄、电话、描述）
- 输入校验：姓名非空、性别限「男/女」、年龄 1~150、电话 11 位数字
- 同名去重：重复添加同名学生会给出提示并拦截
- 数据持久化：学生数据以 JSON 格式保存到本地文件，重启后自动加载
- Excel 导入导出：导出学生信息为 .xlsx 文件、从 .xlsx 批量导入（含校验与去重）
- 退出时自动保存

## 登录与菜单

启动后先登录：

```
1.管理员（密码：123456）      2.普通老师（直接进入）
```

- 管理员菜单：1 添加 / 2 删除 / 3 修改 / 4 查询单个 / 5 查询所有 / 6 保存 / 7 导出Excel / 8 导入Excel / o 退出
- 普通老师菜单：4 查询单个 / 5 查询所有 / 7 导出Excel / o 退出（增删改、保存、导入会被权限拦截）

## 项目结构

```
main.py              # 程序入口
studentcms.py        # 业务逻辑层（登录、菜单、增删改查、校验、存取、Excel导入导出、权限控制）
student.py           # 数据模型层（Student 类）
stu_data.txt         # 学生数据文件（JSON 格式，运行时生成/读取）
docs/开发日志.md      # 开发日志（问题、原因、解决、验证）
```

## 运行方式

需要 Python 3.10+（代码使用了 `match` 语法），并安装依赖：

```bash
pip install openpyxl
python main.py
```

### Excel 文件格式（导入用）

第一行为表头（姓名 / 性别 / 年龄 / 电话 / 描述），第二行起为数据；导入时自动跳过空行、重复姓名与不合规数据。

### 打包成独立可执行文件（无需安装 Python）

```bash
pip install pyinstaller
pyinstaller -F main.py
# 成品在 dist/main.exe，双击即可运行
```

## 技术要点

- 面向对象设计：数据模型（Student）与业务逻辑（StudentCMS）分离，模块化分层
- 角色权限：登录后按角色显示菜单，并在修改类方法内做权限拦截（双保险）
- 通用校验函数 `input_check`：通过 lambda 传入校验规则，添加与修改共用
- 使用 `json` 模块而非 `eval()` 做数据存取，避免代码注入风险
- 使用 `openpyxl` 实现 Excel 导入导出，导入时逐行校验并去重
